Automio 隐私说明

更新日期：2026 年 8 月 25 日

Automio 是本地优先的本地优先的 Android 自动化工具。当前版本不提供账号、云同步、在线内容分发或内置商业统计服务。

本地数据

工作流、Skill、Tool、运行配置、日志和 AI Provider 配置保存在设备本地。您可以导出资源，也可以通过清除应用数据或卸载应用删除这些内容。

权限

无障碍服务用于读取界面元素并执行您发起的点击、滑动和输入。屏幕捕获、通知读取、文件访问、悬浮窗和定时任务权限仅用于对应功能。请只运行可信工作流，并可随时在 Android 设置中撤销权限。

外部服务

只有在您自行配置并调用 AI Provider、MCP 服务或工作流网络请求时，相关输入、屏幕内容或工具参数才会发送到您选择的地址。请核对服务方的传输安全与隐私规则。API Key 使用 Android Keystore 保护，但 HTTP 连接仍可能暴露传输内容。

日志与反馈

崩溃和执行日志默认保存在本地，本项目不会自动上传。提交 issue 或安全报告前，请移除 API Key、个人信息和脚本中的敏感内容。
