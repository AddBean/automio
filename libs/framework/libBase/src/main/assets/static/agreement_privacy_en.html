Automio Privacy Notice

Updated: August 25, 2026

Automio is a local-first, local-first Android automation tool. The app has no account system, cloud sync, resource marketplace, or built-in commercial analytics service.

Local data

Workflows, Skills, Tools, runtime settings, logs, and AI Provider settings you create or import are stored on your device. You can export resources using app features and delete local data by clearing app data or uninstalling the app.

Sensitive permissions

Accessibility is used to inspect UI elements and perform taps, swipes, and text input for automation you initiate. Screen capture, notification access, file access, overlays, and scheduling permissions are used only by their corresponding features. Run only trusted workflows and revoke permissions at any time in Android settings.

External services

Inputs, screen content, or tool arguments are sent outside the device only when you configure and invoke an AI Provider, MCP service, or network request in a workflow. The selected service controls its own data processing. Verify its address, transport security, and privacy policy. API keys are protected with Android Keystore, but plain HTTP can still expose data in transit.

Network and logs

Network access is used to reach services you configure. Crash and execution logs remain local by default and are not automatically uploaded by this project. A workflow may access networks or third-party apps according to its own instructions.

Feedback

Report privacy or security issues through the project repository’s private channels. Remove API keys, personal data, and sensitive script content before sharing logs.
