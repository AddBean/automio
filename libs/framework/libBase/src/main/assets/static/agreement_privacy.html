Automio 隐私说明

更新日期：2026 年 8 月 25 日

Automio 是本地优先的本地优先的 Android 自动化工具。当前版本不提供账号、云同步、资源商场或内置商业统计服务。

本地数据

您创建或导入的工作流、Skill、Tool、运行配置、日志和 AI Provider 配置保存在设备本地。您可通过应用功能导出资源，也可通过卸载应用或清除应用数据删除这些内容。

敏感权限

无障碍服务用于读取界面元素并执行点击、滑动和输入等由您发起的自动化操作。屏幕捕获、通知读取、文件访问、悬浮窗和定时任务权限仅在相应功能需要时使用。请只运行可信工作流，并在系统设置中随时撤销权限。

外部服务

只有在您自行配置并调用 AI Provider、MCP 服务或工作流中的网络请求时，相关输入、屏幕内容或工具参数才会发送到您选择的服务地址。数据处理规则由该服务提供方决定；使用前请核对地址、传输加密和其隐私政策。API Key 使用 Android Keystore 保护，但使用 HTTP 地址仍可能暴露传输内容。

网络与日志

应用需要网络权限以连接您配置的服务。崩溃和执行日志默认保存在本地，不会由本项目自动上传。工作流本身可能访问网络或第三方应用，其行为由工作流内容决定。

反馈

如需报告隐私或安全问题，请使用项目仓库中的 issue 或私密渠道提交。提交日志前请先移除 API Key、个人信息和脚本中的敏感内容。
